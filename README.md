# Heronwatch Site Guides

Editorial source for the Heronwatch Birding Society's printed and web site guides.

Each site the society covers has one folder under `sites/`. A folder holds:

* `overview.md` — the editorial description, with the site's front matter at the top;
* `access.md` — directions, parking and access conditions (only written once a
  volunteer has actually walked the route in);
* `photos/` — the site photographs cleared for publication;
* `notes.md` — free-form volunteer notes, when there are any.

The rules a site has to satisfy before it can appear in a guide edition are kept in
`docs/publishing_standard.md`. Read that before proposing a release.

Guide editions are cut from `main` onto a dated release branch; the branch carries the
manifest that the print shop and the website importer both read.
